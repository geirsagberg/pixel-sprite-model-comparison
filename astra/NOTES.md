Eight right-facing frames run left to right across the 256×32 sheet. Each cell is 32×32 pixels.
The palette has 14 opaque colors plus transparency. The far leg uses darker shades.
The GIF loops every 0.8 seconds at 100 ms per frame, enlarged 8× with nearest-neighbor sampling.
Run `python3 render.py` with FFmpeg on PATH to rebuild both images from `pixels.py`.
